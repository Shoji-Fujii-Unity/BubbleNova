# BUBBLE NOVA（バブルノヴァ）

「バブルシューター・クラシック」の改良版マルチバブルシューター。タイトルは **「宇宙の泡が弾けて新星（ノヴァ）になる」** というイメージで命名しました。

## 遊び方・仕様（原版から継承）

- 11列の六角形グリッド＋上部から降りてくるバブル盤面
- 同じ色を3つ以上つなげて消す（消した数×10点）
- 孤立したバブルは落下（1個×20点）
- **8発ごとに上段が追加**、危険ラインに到達でゲームオーバー
- 盤面を全部消すと **+1000点** して盤面リセット
- 射線上の壁バウンド、着弾点の破線プレビュー
- マウス＋タッチ操作、スコア表示、NEXTバブルのプレビュー
- **7言語対応**（日本語・English・简体中文・한국어・Español・Français・Deutsch）＋自動言語検出＋言語保存

## 改良点（NEW）

| 分類 | 内容 |
|---|---|
| 🎵 サウンド | 効果音10種＋BGMを **Web Audioでリアルタイム合成**（音声ファイル不要）。Howler.jsで再生。🔊/🔇トグル・音量自動フェード・自動再生ポリシー対応 |
| 🎊 エフェクト | 弾けパーティクル、スコアフローター、画面シェイク、盤面全消し時の **canvas-confetti** 祝福、レベルアップ・バナー演出 |
| 🎯 操作性 | **着弾位置のゴースト表示**（どこに付くか事前に分かる）、**NEXTバブルタップで現在／次を交換**、キーボード操作（←→狙う・スペース発射・S交換・Pポーズ・Rリセット）、行追加までの残発数メーター |
| ⏸ ゲーム進行 | ポーズ（手動＋画面非表示時オート）、ハイスコア保存（ベスト更新表示）、消去数・最大コンボ・到達レベルの統計表示 |
| 📈 レベル進行 | 全消しでレベルアップ。レベルに応じて初期行数 5→9、色 4→6、行追加間隔 8→5発 と段階的に難化 |
| ⚠ 警告演出 | 危険ライン接近でラインが赤く脈動＋危険地帯表示 |
| 🌌 見た目 | 星空＋流れ星のアニメ背景、砲身が照準に追従、危険ライン脈動、Orbitron／M PLUS Rounded 1c フォント |
| 🐛 バグ修正 | 原版で行追加時に盤面が2段分支えるグリッド不整合を修正（1段ずつ確実に下降） |

## ネットから取得するライブラリ

| ライブラリ | 用途 | 取得元 |
|---|---|---|
| Howler.js 2.2.4 | サウンド再生 | cdnjs |
| canvas-confetti 1.9.3 | 祝福エフェクト | jsDelivr |
| GSAP 3.12.5 | スコア／パネルのアニメ | jsDelivr |
| Google Fonts（Orbitron / M PLUS Rounded 1c） | 書体 | Google |

いずれもCDNから読み込みます。**オフラインでもライブラリ判定（HAS）がフォールバックに入り、ゲーム自体は通常どおり遊べます**（効果音はWeb Audio合成のため、Howler不在時も `<audio>` で再生）。

## 実行

`index.html` をブラウザ（Chrome / Firefox / Edge / Safari）で開くだけ。音声は初回のクリック／タップ後に始まります。

## 注意

- 効果音／BGMはデータURIにした合成WAVのため、音声ファイルの同梱・ダウンロードは不要です。
- スコア・言語・音声設定は localStorage に保存されます（`nova_best` / `nova_lang` / `nova_sound`）。
